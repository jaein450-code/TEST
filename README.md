# 동탄 맛집노트

동탄 더퍼스트타워2차(경기도 화성시 동탄기흥로 614)를 기준으로 맛집을 등록하고 리뷰를 공유하는 공개 웹앱입니다. 로그인·가입·이메일 인증 없이 누구나 접속할 수 있습니다. 실제 Render 배포 완료는 아직 확인되지 않았습니다.

## 실행

Node.js 24.19.0(`.node-version`)을 권장합니다. 별도 외부 패키지는 없습니다.

```sh
npm run build
npm start
npm test
```

포트는 기본 3000이며 `PORT`로 변경합니다. `DATA_DIR`은 SQLite 저장 경로로, 기본 `.local`입니다. `npm run dev`는 개발 자동 재시작입니다. 기존 체크아웃에서 작업하며 별도 Git worktree는 필요 없습니다.

## 공개 이용

- `/`에서 검색·음식 종류·지역·가격·이동 시간·회식 조건 필터와 맛집 상세를 바로 볼 수 있습니다.
- 누구나 매장과 방문 리뷰를 등록할 수 있고, 다른 방문자도 내용을 읽을 수 있습니다.
- 메일 발송 API·메일 비밀번호·발신 도메인·인증번호는 필요하지 않습니다. 기존 메일 인증 API는 404를 반환합니다.
- 닉네임은 리뷰 작성 시 입력합니다. 계정이나 실제 신원을 확인하지 않습니다.
- HttpOnly/SameSite 쿠키로 브라우저별 작성자를 구분합니다. 본인 브라우저에서는 본인 리뷰만 삭제할 수 있습니다. 쿠키 삭제·만료 또는 다른 브라우저에서는 작성자 권한을 복구할 수 없습니다. 쿠키는 1년 유효합니다.
- 쿠키를 차단해도 조회는 가능하지만 등록·삭제에는 쿠키 허용이 필요합니다.
- 닉네임·방문 날짜·리뷰는 공개됩니다. 개인 연락처 등 민감 정보를 작성하지 마세요.
- 같은 브라우저·식당·방문 날짜의 중복 리뷰는 제한합니다. IP당 10분 60회 쓰기 제한과 브라우저별 일일 등록 제한이 있습니다. 전달 헤더를 무조건 신뢰하지 않습니다.
- 즐겨찾기는 현재 브라우저의 localStorage에 저장됩니다.

## 데이터와 지도

초기 매장 6곳은 가상 예시이며 메뉴·가격·이동 시간·회식 조건이 실제 정보가 아닙니다. 화면과 상세에 표시하며 ‘실제 등록만’으로 제외할 수 있습니다. 별점은 작성된 리뷰로만 계산합니다. 직원용으로 운영하던 기존 데이터가 있다면 공개 전 별도로 검토해야 합니다. 로컬 환경에는 변경 전 실제 등록 매장·리뷰가 없음을 확인했습니다.

도보 시간은 등록자 입력이며 지도 자동 계산이 아닙니다. 네이버지도·카카오맵은 등록한 이름·주소 검색 링크입니다. 리뷰의 방문 날짜는 서울 날짜 기준으로 미래 날짜를 제한합니다.

공식 회사 로고는 아직 확보하지 못해 회사명을 텍스트로 표시합니다.

## 영구 저장과 배포

[DEPLOY.md](DEPLOY.md)를 참고하세요. 운영 시 `NODE_ENV=production`과 HTTPS `PUBLIC_ORIGIN` 또는 Render의 `RENDER_EXTERNAL_URL`이 필요합니다. 브라우저 작성자 정보는 `$DATA_DIR/visitors.sqlite`, 매장·리뷰는 `$DATA_DIR/dining.sqlite`에 저장됩니다. DB는 웹에서 제공하지 않습니다. 기존 `auth.sqlite`가 있더라도 삭제·이관하지 않으며 새 앱은 사용하지 않습니다.

`render.yaml`은 유료 Starter 서버 1개와 영구 디스크 1GB를 정의합니다. 요금 확인 후 생성하세요. 메일 발송 서비스에 가입하거나 발신 도메인을 구매할 필요는 없습니다. 단일 서버 구성이고, 운영 DB 백업·복구와 공개 게시물 관리 정책은 별도로 준비해야 합니다.

## 정적 미리보기

`npm run build`는 가상 데이터만 담은 `index.html`과 `preview.html`을 만듭니다. 서버의 `/preview`나 파일로 열 수 있으며, 등록·리뷰 공유는 동작하지 않습니다. 기존 Netlify 수동 배포 파일은 GitHub 변경만으로 자동 갱신되지 않습니다.

## 네이버 식당 가져오기

`npm run import:naver`는 검토 결과만 저장하고, `npm run import:naver -- --apply`는 수집이 성공한 경우 DB에 중복 없이 등록합니다. `DATA_DIR`에 검토 결과와 DB를 저장합니다.

현재 API HUB용 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`과 공식 지역 검색 요청 URL `NAVER_LOCAL_SEARCH_URL`이 필요합니다. `NAVER_API_PROVIDER` 기본값은 `apihub`이며 인증 화면에 나온 `X-NCP-APIGW-API-KEY-ID`, `X-NCP-APIGW-API-KEY`를 사용합니다. 실제 API HUB 주소는 아직 문서 접근 차단으로 확인하지 못했습니다. `nmap://`나 관리 콘솔 주소를 넣지 마세요. 기존 개발자센터 키만 `NAVER_API_PROVIDER=legacy`로 사용합니다. 키는 소스·채팅에 입력하지 않습니다.

회사 이름과 도로명 주소가 일치하는 유일한 검색 결과를 기준점으로 사용하고, 직선거리 5,000m 밖과 잘못된 좌표·중복·카페를 제외합니다. 검색 결과 수 제한으로 전체 식당을 망라하지 않습니다. 확인되지 않은 메뉴·가격·이동 시간은 임의 입력하지 않습니다. 실제 식당 수집은 아직 완료되지 않았습니다.
